# Câmara Municipal de Jataí

A Câmara Municipal de Jataí é a instituição que exerce o Poder Legislativo no município de Jataí, Brasil.

## Sobre este perfil

Este espaço reúne projetos, ferramentas e informações digitais publicados pela instituição. Explore os repositórios para conhecer o trabalho compartilhado por aqui.

## Nosso papel

O Poder Legislativo municipal representa a população, elabora leis de interesse local e fiscaliza os atos do Poder Executivo, conforme suas competências.
